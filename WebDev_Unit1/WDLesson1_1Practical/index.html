Web Technologies

HTML

HTML uses a browser that recives the HTML file and puts together the web page. Is the standard markup lanuguage used to create and structure content on the world wide web. It uses a system of tags to label different types of content.

CSS

CSS is the code used to design and style how a website looks.It works by targeting an item on the page and stating what changes to make. It is simple and reads almost like regular English. It essentially works as the designer which controls the headings, paragraphs, etc.

JavaScript

JavaScript is a programming language used to make static web pages interactive and dynamic. It allows developers to manipulate HTML elements, control media, and update content on the fly without reloading the page. JavaScript code is embedded directly into or linked from an HTML document using the script tag.
